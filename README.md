# 基于 ESP32 的 BLE Mesh 控制器

本项目包含 ESP32-C3、ESP32-S3 固件以及用于调试和控制的上位机程序，提供 BLE Mesh 节点通信、设备控制和状态交互能力。

## 目录

- `esp32c3/`：ESP32-C3 节点固件
- `esp32s3/`：ESP32-S3 节点/控制器固件
- `app/`：上位机和辅助工具

## 使用方式

请按照对应工程的构建说明配置 ESP-IDF/Arduino 环境，再分别编译烧录。通信参数、串口号和本地路径应通过本地配置提供，不要提交真实设备凭据。
